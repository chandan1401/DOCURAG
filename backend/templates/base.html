DocuRAG Studio Documentation

Architecture, API reference, and keyboard shortcuts

1. System Architecture

DocuRAG combines visual extraction with dense semantic retrieval and sparse lexical keyword search:

Ingestion PDFPlumber & PyMuPDF extract layout, tables, text, and page previews.
Hybrid Retrieval Dense FAISS embeddings combined with Rank-BM25 reciprocal rank fusion.
LLM Generation Gemini 3.5 Flash generates grounded answers with Nvidia NIM fallback.

2. Supported File Formats

.PDF .PNG .JPG / .JPEG .WEBP Max 50MB per file

3. REST API Quickstart

POST /api/documents/upload/ # Multipart form file upload
POST /api/query/ # {"question": "...", "document_ids": [2]}
GET /api/documents/ # List all indexed documents
GET /api/history/ # Query logs with latency metrics
